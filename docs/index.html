asicForTranAI

Reference Fortran kernels and machine-checked proofs for low-precision LLM inference.

For quantized formats (a 3.5-bit pair format and OCP MXFP4 today; INT4 as baseline) the repository provides kernels together with proofs that they cannot overflow and that decoding inverts encoding. Bit-width is a parameter, not the product.

Audited 2026-10-22. Earlier versions of this page and repository stated figures (70B in 19 GB, 4,188 tok/s, 247 proofs) that were wrong, unmeasured or not produced by a prover. They have been removed. Read the audit.

Measured

One thread, scalar kernels, 4096×4096 matrix-vector product, Intel i9-9980HK, gfortran 16.2, median of 15. CPU only: this says nothing about GPUs, accelerators or model accuracy.

On synthetic heavy-tailed weights, MXFP4 has about 4 dB better signal-to-quantization-noise than INT4 at similar bits, and the 3.5-bit pair format is worse than INT4 at equal bits (python3 studies/format_error_study.py).

Not established

  • The proofs cover models that mirror the Fortran, not the Fortran source itself.
  • No accuracy evaluation on a real model; no GPU or accelerator measurements; no NVFP4 yet.
  • The GNATprove used is an Alire build from an intermediate SPARK Pro commit, not a certified release.
