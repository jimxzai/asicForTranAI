Technical notes

3.5-bit pair format

Weights come in pairs: the even-indexed weight is a 4-bit two's-complement integer in [−8, 7], the odd-indexed one is 3-bit in [−4, 3]. A pair is one 7-bit code (even weight in bits 6..3). Eight pairs fill exactly 56 bits, so 16 weights occupy 7 bytes, 3.5 bits per weight with no padding, and 70.6B parameters need about 30.9 GB of weights.

Accumulation is in int32. With |activation| ≤ 128 and |weight| ≤ 8 each term is at most 1024, so the accumulator is safe for up to 2,097,151 terms and one more is unprovable.

MXFP4 (OCP microscaling)

A block is 32 E2M1 values (16 bytes of 4-bit codes) plus one E8M0 scale byte, 4.25 bits per weight. Twice an E2M1 value is an integer in {0,1,2,3,4,6,8,12}, so a block dot product with int8 activations is an exact integer sum (at most 32·128·12 = 49,152), scaled once by a power of two.
